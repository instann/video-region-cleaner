# Codex 实施任务书

你正在接手一个私有 GitHub 仓库 `instann/video-region-cleaner`。请先克隆仓库、完整阅读
`README.md`、`NOTICE.md`、`LICENSE`、`docs/PUBLIC_RELEASE_CHECKLIST.md` 和现有 CLI 源码，
然后把它实现为可供普通 Windows 用户直接使用的桌面应用，并为后续公开 GitHub 发布做好准备。

## 产品定位

这是一个通用、本地运行的“视频矩形覆盖区域修复工具”。用户打开自己拥有或获授权编辑的
视频，在某一帧上手动画出矩形区域，程序读取原始视频像素坐标，预览修复效果，然后导出
一个新视频。不要将产品绑定到任何平台、模型或商标，不要在项目名称、README、截图、
发行说明、界面或 SEO 文案中点名第三方平台，也不要宣传绕过会员、付费或平台限制。

## 必须实现的用户流程

1. Windows 用户双击 EXE 后直接看到应用主界面，不能要求预装 Python。
2. 通过文件选择器或拖放载入 MP4/MOV/MKV/WebM。
3. 显示视频元数据、第一帧，并提供时间滑块、前后帧按钮和时间输入，允许加载任意代表帧。
4. 在预览画布上用鼠标拖拽创建矩形；支持移动、八方向缩放、重新绘制、清除和重置。
5. 正确处理预览缩放、黑边、高 DPI、窗口缩放和不同视频宽高比，把画布坐标精确映射到
   原视频的 `x,y,width,height`，并实时显示数值。
6. 提供“原帧 / 区域标记 / 修复预览”三种查看状态。修复预览只处理当前帧，必须快速。
7. 点击导出后调用现有 OpenCV TELEA 基线逐帧处理，保留音频；源文件永不覆盖，默认输出
   `<原文件名>_clean.mp4`。
8. 显示处理进度、已用时间、预计剩余时间、取消按钮、成功/失败状态和可读错误信息。
9. 自动探测 FFmpeg 和 NVIDIA NVENC；NVENC 实际编码探测成功才使用，否则自动回退
   `libx264`。不要仅凭 GPU 型号判断。
10. 导出结束后用 `ffprobe` 验证输出时长、分辨率、帧率和音频流，并提供“打开文件”和
    “打开所在文件夹”。

## 技术约束

- 优先使用 Python 3.11 + PySide6；若选择其他桌面框架，必须先说明其在视频帧交互、
  Windows 打包、维护成本和许可证方面的优势。
- 核心处理逻辑与 GUI 分层，不能把全部代码堆在一个文件。
- FFmpeg 通过参数数组调用，禁止拼接 shell 命令，必须正确处理中文、空格和特殊字符路径。
- 不在内存中缓存整段视频，不生成全部 PNG 临时帧；继续使用流式逐帧管线。
- 应用默认离线运行，不上传视频、不发送遥测、不读取无关文件。
- 不实现动态字幕清理；当前版本只处理一个固定矩形覆盖区域。界面中不要承诺对复杂动态
  遮挡、动态字幕或所有背景都有效。
- 保留上游 MIT 署名和 `NOTICE.md`，新增依赖必须核查许可证兼容性。
- 不捆绑来源不明的 FFmpeg 二进制。若发行包内置 FFmpeg，必须记录来源、版本、许可证和
  构建选项；否则实现首次启动检测与清晰安装指引。

## 界面要求

- 工作型桌面工具风格，安静、紧凑、清晰，不做营销落地页，不堆卡片。
- 主区域是视频预览；底部是时间控制；右侧是坐标、方法、编码和输出设置；底部或顶部保留
  明确的“导出”主操作。
- 图标优先使用框架自带或成熟图标库；不手绘 SVG；陌生图标必须有 tooltip。
- 矩形框在任何画面上都清晰可见，拖拽手柄尺寸稳定，不能因缩放改变布局。
- 界面文案保持平台中立，仅描述“选择覆盖区域”“修复预览”“导出新视频”。
